# GPUI client check

The GPUI flavour of `tests/fixtures/petstore.json` (`"gpui": true`), regenerated by `cargo test --test generate` in the repository root. It is kept out of the workspace because building GPUI takes a few minutes and a few GB.

Check that it compiles, and lints clean, after changing `templates/query_client.rs` or `src/emit/queries.rs`:

```sh
cd tests/gpui-client
cargo clippy -- -W clippy::pedantic
```
